<objective>
Phase goal (ROADMAP, verbatim): A developer can clone the repo, configure it through environment variables, and run every pipeline stage from any directory with no credentials or personal data in git, CI protecting the code, and a faster IMDb load and embed.

This plan makes embedding concurrent (PERF-04, embed half; D-11) and then measures the whole speedup on real data against the pre-phase code (D-15), with explicit pass thresholds. It also proves the reload does not invalidate unchanged embeddings (D-12/D-13 at DB level) and runs the existing CLI pipeline end to end, which is this project's walking skeleton.

Speed thresholds (ROADMAP SC5 "noticeably faster", made numeric):
- load_imdb at the default --min-votes: old wall time / new wall time must be at least 1.25
- embed on a fixed 2,000-row sample: new rows/sec with --workers 4 / old rows/sec must be at least 1.5

A miss is never a silent pass. It is recorded in the SUMMARY as "SC5 NOT MET" with the numbers and the tuning tried, and surfaced to the user at the end-of-phase check, so the verifier treats it as a gap.

Entry-point order (same as plans 01-01, 01-03 and 01-05): `use_utf8_console()` first, then the argparse parser and `parse_args()`, then `get_db_dsn()` immediately after `parse_args()`.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-19 | Denial of Service | unbounded concurrent Ollama requests / memory | low | mitigate | At most workers*2 futures in flight; --workers must be >= 1; default 4. |
| T-01-20 | Tampering | partial writes on interrupt | low | mitigate | Main-thread writes, one commit per batch, cancel_futures on exception; unwritten rows stay NULL and are picked up on re-run. |
| T-01-29 | Tampering | timing run altering real embeddings | low | accept | Reload is idempotent (upsert) and the 2,000-row sample is re-embedded with the same model, leaving the table fully embedded; N_new - N_old = 0 is checked. |
| T-01-30 | Information Disclosure | DSN printed during timing runs | medium | mitigate | DSN exported via command substitution, never echoed; an acceptance criterion greps .planning for user:password@ DSNs. |
</threat_model>
